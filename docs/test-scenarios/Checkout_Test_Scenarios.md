# Checkout Test Scenarios

## Feature

Checkout

## Objective

Verify that users can complete the checkout process successfully and that required customer information is validated correctly.

## Functional Scenarios

| ID | Test Scenario |
|---|---|
| CHS-01 | Open Checkout Information page from shopping cart |
| CHS-02 | Continue checkout with valid customer information |
| CHS-03 | Verify order overview information |
| CHS-04 | Verify product information on Checkout Overview page |
| CHS-05 | Verify item total is calculated correctly |
| CHS-06 | Verify tax is displayed |
| CHS-07 | Verify total amount is calculated correctly |
| CHS-08 | Complete checkout successfully |
| CHS-09 | Verify order confirmation message after successful checkout |
| CHS-10 | Cancel checkout from Checkout Information page |
| CHS-11 | Cancel checkout from Checkout Overview page |

## Validation Scenarios

| ID | Test Scenario |
|---|---|
| CHS-12 | Continue checkout with empty First Name |
| CHS-13 | Continue checkout with empty Last Name |
| CHS-14 | Continue checkout with empty Postal Code |
| CHS-15 | Continue checkout with all customer information fields empty |
