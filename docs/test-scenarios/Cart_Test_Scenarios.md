# Shopping Cart Test Scenarios

## Feature

Shopping Cart

## Objective

Verify that users can add, view, update, and remove products in the shopping cart and proceed to checkout correctly.

## Functional Scenarios

| ID | Test Scenario |
|---|---|
| CS-01 | Open shopping cart from the Products page |
| CS-02 | Verify that an added product is displayed in the cart |
| CS-03 | Verify product information in the cart |
| CS-04 | Add multiple products to the cart |
| CS-05 | Verify cart badge count after adding multiple products |
| CS-06 | Remove one product from a cart containing multiple products |
| CS-07 | Verify cart badge count after removing one product |
| CS-08 | Remove all products from the cart |
| CS-09 | Verify cart badge is not displayed when cart is empty |
| CS-10 | Continue shopping from the cart |
| CS-11 | Verify products remain in the cart after returning to the Products page |
| CS-12 | Open checkout from a cart containing products |
