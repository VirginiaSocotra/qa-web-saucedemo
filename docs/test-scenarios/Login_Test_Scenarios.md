# Login Test Scenarios

## Feature

User Authentication

## Objective

Verify that users can authenticate with valid credentials and that the application correctly handles invalid, missing, or restricted credentials.

## Functional Scenarios

| ID | Test Scenario |
|---|---|
| LS-01 | Login with valid username and valid password |
| LS-02 | Login with valid username and invalid password |
| LS-03 | Login with invalid username and valid password |
| LS-04 | Login with invalid username and invalid password |
| LS-05 | Login with empty username |
| LS-06 | Login with empty password |
| LS-07 | Login with both username and password empty |
| LS-08 | Login with a locked-out user |
| LS-09 | Logout after successful authentication |
