# SauceDemo Test Plan

## Test Objectives

The objectives of testing are to:

- Verify that the main user flows work correctly.
- Identify functional and UI defects.
- Verify input validation and error handling.
- Verify shopping cart behavior.
- Verify the checkout process.
- Evaluate the application through exploratory testing.
- Create reusable regression and smoke testing checklists.

## In Scope

- Login functionality
- Product catalog
- Product details
- Product sorting
- Shopping cart
- Checkout process
- Navigation menu
- Logout functionality
- Basic UI validation
- Error messages

## Out of Scope

- Backend testing
- Database testing
- API testing
- Performance testing
- Security penetration testing
- Real payment processing
- Large-scale cross-browser/device testing

## Test Environment

Application: SauceDemo Web Application

URL: https://www.saucedemo.com/

Platform: Desktop Web

Browser: Chrome

Operating System: macOS

Test Type: Manual Testing
